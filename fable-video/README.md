# Fable 5.2 capabilities video

A 57-second, 3840x2160 (4K) motion-graphics explainer of what Claude Fable 5.2 can do,
built with [Remotion](https://www.remotion.dev).

```sh
npm install
npm run dev      # preview and edit in Remotion Studio
npm run render   # writes out/fable-5-2-capabilities-4k.mp4 (needs ffmpeg)
```

- Scenes live in `src/scenes/`; order and lengths are set in `src/Video.tsx`.
- Colours, fonts and shared layout are in `src/theme.tsx` (linen, olive and one rust accent; light serif headlines with tracked-caps labels).
- The soundtrack is a synthesized ambient pad generated by `scripts/render.sh`; swap in
  your own music by replacing `out/ambient.wav` in that script.
